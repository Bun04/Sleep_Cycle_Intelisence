Thường Gặp

File CSV cần như thế nào?

File phải có header row và chứa các cột: Sleep Hours, Deep Sleep, REM Sleep, HRV, RHR, Awakenings, SpO2. Tên cột có thể bằng tiếng Anh hoặc Việt.

Kết quả phân tích bao gồm gì?

Recovery Score, phân loại chất lượng, cảnh báo Sleep Apnea, mức stress, dự báo năng lượng, khuyến nghị, chu kỳ giấc ngủ.

Backend chọn thuật toán như nào?

Hệ thống phân tích độ phức tạp (stress, apnea risk, sleep gap) và tự chọn: Linear Regression, Logistic Regression, Random Forest, hoặc KNN.

Dữ liệu có được lưu không?

Tất cả dữ liệu được lưu để bạn theo dõi lịch sử. Bạn có quyền quản lý dữ liệu của mình.
